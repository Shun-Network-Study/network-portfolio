# ネットワーク構築演習ポートフォリオ

## 自己紹介・ポートフォリオの概要
前職は映像ディレクターとして従事しておりましたが、より長期的な成長と社会的な安定を求め、IT業界へのキャリアチェンジを決意し、未経験からネットワークエンジニアを志望しております。<br>
重要な社会基盤を支えるネットワーク技術に強い関心を持ち将来性を感じ、2025年5月にCCNA（Cisco Certified Network Associate）を取得しました。<br>
現在は、ネットワーク構築スキルをさらに高めるため、Cisco Packet TracerとCisco Modeling Labsを用いたハンズオン学習に取り組んでいます。

このリポジトリでは、「ネットワーク構築マラソン」（株式会社CAIRN 運営）に取り組み、ネットワーク構成図、設定内容、検証結果などをまとめています。<br>
実務未経験ではありますが、実務を想定した構築課題に取り組み、設定ミスの切り分けや通信確認などのトラブルシューティングの思考過程を可視化しています。<br>
本ポートフォリオを通じて、私の技術力と学習姿勢を採用担当者の方にお伝えできればと考えております。

## 技術スキル
- **Cisco機器**: Layer2 Switch・Router・基本的なCLI操作
- **ネットワーク基礎**: OSI参照モデル・TCP/IP・IPアドレッシング（VLSM・CIDR）・IPv6基本設定
- **スイッチング**: VLAN・STP・EtherChannel
- **ルーティング**: スタティックルーティング・OSPF
- **ネットワークサービス**: DHCP・NAT（スタティックNAT・ダイナミックNAT・NAPT）
- **セキュリティ**: ACL（標準ACL・拡張ACL）・基本的なスイッチセキュリティ・無線LAN
- **トラブルシューティング**: ping・traceroute・showコマンド・debug
